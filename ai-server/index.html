EXECUTION ROADMAP

5-Phase Step-by-Step Deployment Guideline

Follow this step-by-step workflow to configure your hardware, install the AI stack, and run local agents.

01

Phase 1: Host OS Setup & NVIDIA Driver Installation

Est: 20 Mins

Install Ubuntu Server 24.04 LTS (or Windows 11 with WSL2). Verify that your GPU is detected and install the proprietary NVIDIA graphics drivers.

Terminal (Ubuntu / Linux) 
# 1. Update package lists and install kernel headers
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential dkms linux-headers-$(uname -r)

# 2. Install recommended NVIDIA display drivers
sudo ubuntu-drivers install
sudo reboot

# 3. Verify driver and CUDA detection
nvidia-smi
02

Phase 2: Install Docker Engine & NVIDIA Container Toolkit

Est: 15 Mins

Install the Docker engine and configure the NVIDIA Container Toolkit so containerized services can directly allocate GPU VRAM and Tensor Cores.

Terminal (Bash) 
# 1. Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# 2. Add NVIDIA Container Toolkit repository
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

# 3. Install and configure runtime
sudo apt update && sudo apt install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

# 4. Verify GPU passthrough inside Docker
docker run --rm --gpus all nvidia/cuda:12.2.0-base-ubuntu22.04 nvidia-smi
03

Phase 3: Deploy the Unified AI Stack (Docker Compose)

Est: 10 Mins

Spin up Ollama (Inference), LiteLLM (Gateway), Qdrant (Vector DB), and Open WebUI in a single coordinated environment.

Terminal (Bash) 
# Create project directory
mkdir -p ~/ai-server && cd ~/ai-server

# (Save docker-compose.yml and litellm-config.yaml into this folder)
# Launch all services in background:
docker compose up -d

# Verify all containers are running
docker compose ps
04

Phase 4: Pull & Benchmark Core Models

Est: 15 Mins

Download your primary reasoning model, coding assistant, and high-performance embedding model into the local inference engine.

qwen2.5-coder:14b
Agent Logic & Coding
VRAM: ~14 GB (Q8)
docker exec -it ollama ollama pull qwen2.5-coder:14b
deepseek-r1:14b
Deep Chain-of-Thought
VRAM: ~12 GB (Q4)
docker exec -it ollama ollama pull deepseek-r1:14b
bge-m3
Multilingual RAG Embeddings
VRAM: ~1.2 GB
docker exec -it ollama ollama pull bge-m3
05

Phase 5: Connect Web UI, Dify & LangGraph

Est: 20 Mins

Access your web interface at http://<SERVER-IP>:3000. Connect your local models to Dify for visual pipelines and execute LangGraph Python scripts against the local OpenAI-compatible endpoint.
